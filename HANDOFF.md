## 1. Что за проект

Одностраничная интерактивная статистика Steam-профиля в стиле Spotify Wrapped /
Redline. Чистый ванильный стек: **никаких фреймворков, сборщиков и UI-библиотек**.

### Файлы
| Файл | Роль |
|---|---|
| `index.html` | разметка: hero, marquee, секции 01–07, футер |
| `assets/css/style.css` | дизайн-система, адаптив |
| `assets/js/app.js` | вся клиентская логика, интерактив, Canvas-карточка (~2600 строк) |
| `assets/js/profile-data.js` | слой нормализации/валидации данных (XSS-safe) |
| `assets/js/data.js` | **READ-ONLY** сгенерированный профиль (не трогать руками!) |
| `assets/data/rules.json` | словарь жанров, фильтры мусора, коэффициенты |

### Дизайн-система «Redline / Dark Espresso»
- Фон `#0A0807`, карточки `#141110`, текст `#EDEDEF`
- Палитра (приглушена в этой сессии): `--c1 #BA3636`, `--c2 #9C2E28`, `--c3 #772420`, `--c4 #E07A6B`
- Шрифты: `Unbounded` (дисплей), `Golos Text` (текст), `JetBrains Mono` (цифры/теги)
- **Запрещено:** градиентный текст, `-webkit-text-stroke`, фиолетовый неон

### Железные правила разработки
1. Одна задача за раз: план 2–4 предложения → подтверждение → реализация → проверка в Preview (десктоп+мобилка) → коммит → пуш.
2. Pre-commit: `node --check assets/js/app.js`; баланс `{`==`}` в CSS; `<div`==`</div` в HTML; **бамп версий** `style.css?v=` и `app.js?v=` в `index.html`.
3. Правки в файлах — скриптами (python) с проверкой уникальности совпадения (`assert count == 1`).
4. Сервер для превью: `python3 -m http.server 8000 --bind 0.0.0.0`.

### Что хочет пользователь

шрифт, размеры, цвета — **но каждое предложение сначала согласовывается с ним**.

### Формат работы
1. Сгенерируй 2–3 концепт-картинки hero (generate_image, палитра «кирпич»).
2. Покажи пользователю через `present_file`, дождись выбора/правок.
3. Реализуй по шагам (см. правила), после каждого шага — проверка в Preview.

### 🕳 Грабли, на которые мы уже наступили (не повторяй)
- **`measureText` врёт дважды:** HTML-текст `Steam` ≠ рисуемый капс `STEAM` (меряй
  uppercase), и `letter-spacing` canvas не видит (`ctx.letterSpacing` есть не везде —
  есть ручной фолбэк `ls * (len-1)`).
- **`getBoundingClientRect` спана-`display:block` всегда равен колонке** — о переливе
  не сигнализирует. Фактическую ширину глифов меряй через
  `Range.selectNodeContents(span)` + докрутка итерациями.
- Unbounded **шире** любых расчётных множителей; CSS `vw`-фит — только fallback.
- Счётчик цифры на Unbounded «гуляет» — для анимированных цифр только
  `JetBrains Mono` + `tabular-nums`.
- Hero использует `--px/--py/--mx/--my` (дрейф за курсором) — живёт в `app.js`,
  поиск по «titleFit», «heroTicket», «pointermove».
- Не оставляй в CSS `//`-комментариев (только `/* */`), не дублируй рамки-линейки
  вокруг marquee (уже была жалоба на «две линии»).
- После каждого коммита — бамп `?v=` + пуш строго в `arena/<текущая>` ветку сессии.

Удачи. Работай маленькими шагами и согласовывай — пользователь включён и внимателен.
